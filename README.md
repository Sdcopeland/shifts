# Introduction 
Shift Sync is a lightweight progressive web app focused app to make it easy for shift workers to manage their schedules and sync to their preferred calendar provider. It additionally has some useful tools to help track varied income for shift workers with differentials for various shifts. 

# Instructions
Test out Shift Sync at <https://shifts.civiclabs.io>

## To Enable Persistence
1. Visit the website on your mobile browser
2. Go to the share menu to share the website
3. Find option to 'Add to Home Screen'
4. This creates a persistent version that will store your data on your phone.

## Features
- Light & Dark Modes 
- Custom Shift Times 
- Pay Tracking
- Custom Weekend and Night Time Pay Differentials
- Calendar Sync
